# Release notes: v0.2.0 integration (2026-11-11)

v0.2.0 combined seven feature branches into one release. In merge order, they brought:

1. `install.sh`: `fs.pipe-user-pages-soft = 0`, so pipe restores do not fail once many desktops share a host.
2. One host uid/gid range per env (`idrange.rs`), `tenantvm/`, and a portable `make-release.sh`.
3. A reward audit on every verify, and `no_app_crash` crash attribution by cgroup census.
4. Events-based quiescence, CRIU `-v3` logs, and the `netns_fast` and `restore_cpu_boost` defaults.
5. Incremental capture, prefork, the restore `cpu.weight` boost, pidfd waits and `max_concurrent_restores`.
6. `crates/drums-pool` (many hosts) and the `pool/` tooling.
7. `crates/drumsd-os` (Android and Windows pools) and `osvm/`.

The matching drums-criu, SDK and verifiers commits are pinned in `install/lock.json`. One conflict needed a decision:
two CRIU options had both taken getopt code 1107 in `criu/config.c`; `--userns-remap` keeps 1107 and
`--prev-images-uptime` moved to 1108.

The commit-level detail is in [CHANGELOG.md](../../CHANGELOG.md) and in `git log`.
